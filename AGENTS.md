Production search notes:

- This repo is the source of truth for the live Meilisearch `jobs` index.
- The `jobs` index primary key must be `meili_id`, not raw `id`. Raw job ids can contain `.` and are not safe as Meili document ids.
- Keep both fields in documents: `id` is the canonical job id; `meili_id` is the deterministic Meili-safe surrogate from `public_ids.meili_safe_job_id`.
- Do not run a full Meili `jobs` reload unless it is truly necessary (for example index corruption, primary-key migration, or an intentional full rebuild). Prefer targeted reloads or partial document updates so we do not reinsert and re-embed the whole corpus.
- With the embedder enabled, partial Meili updates must still include enough searchable text (for example `title`/`company`) for embedding to succeed; a tiny field-only patch can fail with `vector_embedding_error`.
- Document vectors are computed in the pipeline (`embeddings.py`, OpenRouter `perplexity/pplx-embed-v1-0.6b`, 512 dims, L2-normalized) and sent as `_vectors.default` with `regenerate: false`, so Meili never embeds documents during indexing. `render_document_text` must stay byte-identical to the embedder's `documentTemplate` (liquid-rust `truncatewords` splits on single spaces; empty strings are truthy). If the template, model, or dimensions change, change Meili's search embedder to match and rebuild into a new index, then swap; Meili cannot detect a query/document vector mismatch.
- Meilisearch runs 1.56.1 (upgraded from 1.39.0 on 2026-11-08). Since 1.44, query embedding at search time is bounded by the index's `searchCutoffMs` (default 1500 ms).
- If the index gets mixed/corrupted, the safe repair is: delete `jobs`, then run a clean DB-backed full reload.
- Internal background Meili traffic should use `https://search-internal.dopejobs.xyz`, not `search.dopejobs.xyz`.
- `search-internal.dopejobs.xyz` is Cloudflare-proxied, protected by Cloudflare Access service-token headers, and origin-blocked for non-Cloudflare source IPs.
- The Hetzner origin exempts Cloudflare IP ranges from the coarse `80/443` connection throttle. If internal access breaks, first verify Cloudflare Access headers and then refresh the Cloudflare IP allowlist on the origin.
- Index profiles (`index_profiles.py`, `PIPELINE_INDEX_PROFILE`):
  - `pplx512` (default) is today's `jobs` index.
  - `v2` is the voyage/student index:
    - voyage-4-lite native 1024d docs (`input_type: document`), L2 → `models/proj_clean_voy4_1024_to_256.npy` (sha256 pinned in embeddings.py) → L2 = 256d
    - slim docs (`V2_DROP_FIELDS`)
    - lean settings plus a single **rest** embedder (a composite fails Meili's search-vs-indexing similarity check for asymmetric encoders) with an explicit `distribution` 0.75/0.1. That's the shift the best student row was measured with; keep the frontend at semanticRatio 0.8. In v2 the pipeline never sends docs without vectors.
  - Queries come from the box proxy's `/openai-search-tiny` (the tiny student) in the same 256d space.
  - The loader refuses to write one profile's vectors into an index whose embedder has the other's dimensions.
  - `/openai-search-tiny` must be live before v2 searches.
  - Prod Meili allows loopback embedder URLs (`MEILI_EXPERIMENTAL_ALLOWED_IP_NETWORKS=127.0.0.1/32`).
  - Scheduled loads follow the repo variable `PIPELINE_INDEX_PROFILE`; flip it only at the index swap.
